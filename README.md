# MSE Superbrain OS v3

可直接部署至 Netlify、GitHub Pages 或一般靜態主機，無需建置指令。

## 最快部署

### Netlify Drop
1. 將整個資料夾壓縮為 ZIP（本交付已完成）。
2. 登入 Netlify，進入 Deploy manually / Drop。
3. 可直接拖入 ZIP；若介面不接受，再解壓後拖入整個資料夾。
4. 等待產生網址後，先測試首頁、Prompt、任務與重新整理保存。

### GitHub Pages
1. 將本資料夾內所有檔案放在 repository 根目錄。
2. Settings → Pages → Deploy from a branch。
3. 選擇 `main` 與 `/ (root)` 後儲存。

## 隱私守門

- 預設只使用瀏覽器 localStorage，不含 Firebase 或任何 API 金鑰。
- 外部 AI 僅由使用者按鍵後開啟，Prompt 需自行貼上。
- 請勿輸入身分證、病歷、帳密、金融或公司機密。

## 驗收入口

右上角「設定」→「執行自我檢測」。完整使用方式在首頁「功能特色導覽／小白操作指南」。
