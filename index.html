全功能操作指南

第一次使用，照著四條路走即可。

🧠 1. 建立好 Prompt
  1. 首頁點「Prompt 鍛造」。
  2. 至少填寫「任務」，角色、格式、限制可補強結果。
  3. 按「生成 Prompt」，可複製、匯出或選擇一個 AI 開啟。
⚖️ 2. 比較三個 AI
  1. 將 Prompt 分別交給不同 AI。
  2. 把回覆貼進對應欄位，至少填一份。
  3. 按「生成交叉裁定草稿」；它會忠實並列，不會冒充 AI 自動判斷。
  4. 將草稿再交給 AI 做最終綜整，或匯出到 NotebookLM。
⏱️ 3. 專注計時
  1. 選 5 分、25 分或輸入 1–180 分鐘。
  2. 按開始；可暫停、繼續、重置。
  3. 完成時依設定播放提示音與震動。
✅ 4. 管理任務
  1. 輸入任務後按新增。
  2. 點任務文字切換完成；點垃圾桶刪除。
  3. 「清除已完成」會先要求確認。
⚙️ 5. 設定、備份與安裝
  1. 右上角設定可切換明暗模式、調整字級、提示音與震動。
  2. 「匯出 JSON」可備份；匯入前會驗證格式與大小。
  3. 支援的瀏覽器可按「安裝 App」加入桌面；離線仍可使用本機功能。
🔐 隱私與安全

所有內容預設只存於這台裝置的瀏覽器。程式不內含 API 金鑰，不會自動把 Prompt 或任務送到外部服務。使用外部 AI 時，仍請勿貼上身分證、醫療、金融或機密資料。
